How It Works - Step by Step
1.	Start: Program initializes empty attendance dictionary.
2.	Input Name: User enters a person's name.
3.	Check Exit: If name is "exit", program stops.
4.	Input Status: User enters attendance status (Present/Absent).
5.	Validate: If status is invalid, user must re-enter.
6.	Save: Attendance is saved to dictionary.
7.	Display: All current attendance records are shown.
8.	Repeat: Loop continues for next entry.
